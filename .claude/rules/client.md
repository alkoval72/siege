# Правила клиента `client/src`

Правило действует только для исходников клиента.

## Клиент не знает правил

- Допустимые ходы берутся только из `legalMoves`, которые присылает сервер. Логику движка (единство группы, скольжение, ходы фишек) в TypeScript не дублируй.
- Подсветка «недопустимо» вычисляется на клиенте только для отображения: красным отмечаются пустые клетки, прилегающие к группе, за вычетом допустимых.
- Цвет подсветки всегда сопровождается значком: точка для допустимой клетки, крестик для недопустимой.

## Компоненты

- Только `<script setup lang="ts">` и Composition API. Props и события типизируются через `defineProps<...>()` и `defineEmits<...>()`. Options API и `any` не используются.
- Компоненты только рисуют. Геометрия и подсветка живут в чистых функциях в `src/game/*.ts`.
- Названия, описания и картинки фишек берутся из `src/themes/<тема>/theme.json`. Тексты вроде «Король» в компонентах не хардкодятся.
- DTO описываются в `src/api/types.ts`: camelCase, дискриминатор хода `kind`.
- Тексты интерфейса пишутся на русском.

## Тесты и проверка

- Новые unit-тесты для клиента пишутся только по запросу, в отличие от движка.
- После правки: `npm --prefix client run lint`, `npm --prefix client run type-check`, `npm --prefix client run test:unit`. Для видимых изменений интерфейса ещё `test:e2e` или проверка через Playwright MCP.
