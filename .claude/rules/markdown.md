# Оформление Markdown-файлов

Правило действует для всех `.md`-файлов проекта: `CLAUDE.md`, `README.md`, `docs/*.md`, правил и навыков в `.claude/`.

## Текст

- Пиши на русском. Идентификаторы, команды, пути и названия технологий оставляй в оригинале.
- Не используй длинное тире (U+2014). Вместо него ставь двоеточие, запятую, скобки или перестраивай фразу. В диапазонах используй дефис (`M0-M7`).
- Кавычки в русском тексте пиши «ёлочками», в коде и командах оставляй прямые.
- Даты указывай в формате `ГГГГ-ММ-ДД`.
- Абзац занимает одну строку, вручную внутри абзаца строки не переносятся.
- Без эмодзи.

## Структура

- В файле один заголовок первого уровня `#`, в самом начале. Уровни заголовков не пропускаются.
- В нумерованных документах (`spec.md`, `architecture.md`) разделы нумеруются так: `## 5. Правила игры`, `### 5.1 Общее`. Ссылка на раздел выглядит как `§5.1`.
- Заголовки, списки, таблицы и блоки кода отделяются от окружающего текста пустой строкой.
- Для маркированных списков используй `-`, вложенный уровень сдвигается на 2 пробела. Нумерованные списки нужны только там, где важен порядок.
- Жирный шрифт применяй для ключевых терминов, по одному-два на абзац, а не для целых предложений.

## Код, пути и ссылки

- Имена файлов, папок, типов, методов, команд и значений настроек пиши в `обратных кавычках`.
- Блоки кода оформляй тремя обратными кавычками с языком: `csharp`, `ts`, `vue`, `json`, `bash`. Для деревьев файлов и схем указывай `text` или оставляй без языка.
- Ссылки на файлы проекта делай относительными путями: `[architecture.md](docs/architecture.md)`.

## Таблицы

- У таблицы всегда есть строка заголовков и разделитель `|---|---|`.
- Ячейки короткие. Если нужно больше одного предложения, вынеси текст в список под таблицей.

## Документы проекта

- Решения, меняющие `spec.md` или `architecture.md`, записываются в журнал решений этого документа.
- `docs/plan.md`: задачи оформляются чекбоксами `- [ ]` / `- [x]`, выполненные задачи не удаляются.
- `docs/memory.md`: новые записи добавляются в конец, старые не переписываются.
