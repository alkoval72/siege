# Передача работы

## 1. Собери факты

- `git log --oneline -10`, `git status --short`, `git diff --stat`: что изменилось с последней записи журнала.
- Последняя запись `docs/progress.md`: с какого места начиналась работа.
- Что было проверено в этой сессии (сборка, тесты, линтеры) и с каким результатом.

Пиши только то, что подтверждается фактами. Если проверка не запускалась, так и напиши.

## 2. Обнови `docs/plan.md`

- Отметь `[x]` пункты, которые действительно выполнены и проверены.
- Выполненные пункты не удаляй. Новые задачи, появившиеся по ходу работы, добавь `[ ]` в подходящий шаг.
- Обнови строку «Обновлено:» текущей датой.

## 3. Добавь запись в конец `docs/progress.md`

Старые записи не меняй. Формат:

```markdown
## ГГГГ-ММ-ДД, Claude Code: <задача из аргумента или краткое описание>

- **Сделано:** что изменено и что проверено
- **Решения:** что выбрано и почему
- **Дальше:** первый незакрытый пункт `plan.md`
- **Ловушки:** что может помешать следующему исполнителю
- **Коммит:** хеш или «не закоммичено»
```

Если по полю нечего сказать, пиши «нет». Без длинного тире.

## 4. Отчитайся

Одной-двумя строками: какие пункты отмечены и какой следующий шаг. Предложи сообщение коммита для handoff-файлов, сам не коммить.
