## Пользователи и сценарии
- source: docs/spec.md §1, §3

DATA_TQxznC48_START
Игроки: владелец, семья, друзья. Основные сценарии:
1. Игрок вводит имя, создаёт партию и отправляет ссылку-приглашение сопернику.
2. Двое игроков по очереди ставят и перемещают фишки.
3. Игра сообщает о победе, ничьей или пропуске хода.
4. После разрыва связи игрок возвращается в ту же партию.
5. Двое играют на одном экране в локальном режиме.
DATA_TQxznC48_END

Цели владельца (spec §1): играбельная игра для семьи и друзей; отработка полного цикла работы с Claude Code (spec → архитектура → `CLAUDE.md` → hooks и skills → разработка с тестами). Разработчик один, графику готовит с помощью Claude.
