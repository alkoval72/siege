# Журнал работ: Siege

Это handoff-файл: журнал прогресса для продолжения работы в новой сессии или другим агентом. Текущее состояние задач хранится в `docs/plan.md`, детали изменений в git log.

Правила ведения:
- запись добавляется после каждой завершённой задачи, только в конец файла; старые записи не переписываются;
- заголовок записи: `## ГГГГ-ММ-ДД, <агент>: <задача>`;
- обязательные поля: «Сделано», «Решения», «Дальше», «Ловушки», «Коммит»; если по полю нечего сказать, пиши «нет»;
- если коммита ещё нет, в поле «Коммит» пиши «не закоммичено», следующая запись указывает хеш.
